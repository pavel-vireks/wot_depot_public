# WoT Depot

Мод для World of Tanks: выгружает весь ангар — оборудование, снаряжение,
боевые бустеры, снаряды, экипаж, стили и кастомизацию, плюс остатки на складе —
в CSV и в интерактивную HTML-страницу.

**Клиент:** 2.4.0.0 · **Версия мода:** 0.2.0

## Установка

Способ 1 — папка `res_mods` (рекомендуется):

1. Скачай `wot_depot_0.2.0_res_mods.zip` из [Releases](../../releases).
2. Распакуй в папку с игрой так, чтобы получилось:
   ```
   <папка игры>\res_mods\2.4.0.0\scripts\client\gui\mods\mod_tank_report.pyc
   ```
3. Запусти игру.

Способ 2 — файл `.wotmod`:

1. Скачай `wot_depot_0.2.0.wotmod` из Releases.
2. Положи в `<папка игры>\mods\2.4.0.0\`.
3. Запусти игру.

## Использование

В ангаре нажми **Ctrl+F9**. Мод соберёт ангар и откроет отчёт в браузере.
Файлы также лягут в `<папка игры>\tank_report\`:

- `hangar_long_<дата>.csv` — одна строка на предмет, для сводных таблиц;
- `hangar_wide_<дата>.csv` — одна строка на танк;
- `hangar_<дата>.html` — три вкладки (танки со сворачиванием, сводка по
  предметам, плитки оборудования с иконками из ресурсов игры), поиск,
  фильтры по нации/классу/уровню, галки «премиум / коллекционный / акционный»,
  фильтры по содержимому танка и «экипаж с 0-перком», кнопка «назад».

CSV — UTF-8 с BOM и разделителем `;`, Excel открывает двойным кликом.

## Настройка (необязательно)

Положи `tank_report.json` в папку с игрой:

```json
{
  "hotkey": "KEY_F9",
  "hotkeyRequiresCtrl": true,
  "browserMode": "system",
  "styleDetails": false,
  "hideCustomizationTypes": ["emblem"],
  "chunkSize": 25
}
```

`browserMode`: `system` — обычный браузер (по умолчанию), `file` / `http` —
встроенный браузер клиента, `off` — только файлы.

## Совместимость

Собрано под клиент **2.4.0.0** (Python 2.7). На других версиях загрузчик модов
может не подхватить — нужна папка `res_mods\<твоя версия>\`.

---

Мод распространяется в скомпилированном виде. Ничего не отправляет в сеть:
локальный HTTP-сервер (режим `http`) слушает только петлю `127.0.0.1`.
